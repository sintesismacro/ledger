# Letters

One letter a quarter, merged as a pull request (`letters/2027-Q1.md` onwards). Each letter
states which probabilities moved, by how much and on what evidence, so that the diff is the
history of revised belief. Each ends with one line on what SINTESIS verifies for funds.
